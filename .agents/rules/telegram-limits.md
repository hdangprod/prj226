# Telegram Limits & Formatting Rules

## 1. Rule Statement
All Telegram bot text messages and notifications generated by skills or the intent router MUST comply with Telegram Bot API payload, rate limit, and HTML formatting constraints to prevent delivery failures (HTTP 400/429).

## 2. Implementation Guidelines
1. **Message Length Limit**: Single message text MUST NOT exceed **4096 characters**. Use chunking or truncation if text exceeds limit.
2. **HTML Formatting Subset**: Telegram supports ONLY a specific subset of HTML tags: `<b>`, `<i>`, `<u>`, `<s>`, `<code>`, `<pre>`, `<a>`, `<blockquote>`. Do NOT send unsupported tags (e.g. `<div>`, `<p>`, `<h1>`, `<br>`).
3. **Rate Limits**: Limit sending messages to a single user to a maximum of 1 message per second, and global bot output to 30 messages per second.
4. **Resilient Delivery**: Always wrap `sendMessage` calls in error handlers (`.catch(() => {})`) when executed inside `ctx.waitUntil()`.
