# Second Brain Methodology & CODE Framework

This document summarizes the core principles of Tiago Forte's **CODE Framework** as processed by OpenWiki:

- **Capture**: Store raw ideas in Notion `notes_staging`.
- **Organize**: Categorize into PARA (Projects, Areas, Resources, Archives).
- **Distill**: OpenWiki synthesizes raw notes into structured OKF Markdown files in `./vault`.
- **Express**: Retrieve context instantly via Telegram assistant using vector search (`knowledge_wiki`).
